# EP.133 어머니의 아버지, 아들의 어머니, 첫째 딸 — 영조가 다시 불러 준 이름들 — 한국학중앙연구원 장서각 · 홍보 세트

## 1. 릴스·쇼츠 (9:16) 게시 글
```
📜 고문서 한 장 EP.133 〈어머니의 아버지, 아들의 어머니, 첫째 딸 — 영조가 다시 불러 준 이름들〉

🕯️ 이름 없이 '첫째 옹주'로만 불린 딸에게, 여든의 영조가 이름을 지어 주었습니다.

왕이 된 영조는 이름을 높여 주는 교지를 여러 번 내린다. 1734년에는 무관의 낮은 자리에 머물렀던 외할아버지 최효원을 영의정으로 추증한다. 어머니 숙빈 최씨의 사당 육상궁에는 노비를 내려 '누구의 몇째 자식'까지 적는다. 1765년에는 사도세자의 어머니 영빈 이씨에게 '의열'이라는 시호를, 1773년에는 이름 없이 '첫째 옹주'로 불리던 딸에게 '화억'이라는 이름을 준다

1734년. 왕이 된 영조가 외할아버지의 이름을 다시 부른다. 살아서는 종6품 무관이던 사람이다. 옆에 작은 글씨. "숙빈의 아버지이므로 벼슬을 추증한다(淑嬪考 贈職事)." 낮은 자리의 이름이, 영의정이 되었다.
어머니의 사당에도 사람이 내려진다. 그런데 이번엔 이름만이 아니다. "계집종 석녀의 셋째 자식, 사내종 일부, 나이 마흔하나(婢石女三所生奴日夫年四十一)." 누구의 몇째 자식인지까지. 어머니를 기리는 문서에, 다른 어머니들의 이름이 줄지어 적혔다.
1765년. 한 해 전 세상을 떠난 후궁에게 시호가 내려진다. 사도세자의 어머니다. "영빈 이씨에게 시호 '의열'을 내린다(暎嬪李氏贈諡義烈嬪者)." 두 글자 안에 무엇이 담겼는지, 종이는 말하지 않는다.
그리고 1773년, 여든의 임금이 또 하나의 이름을 부른다. 이름조차 없이 '첫째 옹주'로 적혀 있던 딸이다. "첫째 옹주에게 화억옹주를 추증한다(一翁主贈和憶翁主者)." 늙은 아버지는 끝내, 딸에게 이름을 지어 주었다.

이번 릴스에서는 장서각에 전하는 영조 대의 증직교지 · 노비사패교지 · 증시교지를 원문 그대로 읽어 봅니다. 이 기록을 바탕으로 Claude 플러그인 aks-archive-harvester로 전시 웹페이지, 카드뉴스, 수업 활동지, SNS 게시글을 만들었습니다.
```
