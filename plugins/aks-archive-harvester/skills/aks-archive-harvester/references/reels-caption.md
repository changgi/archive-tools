# 릴스 홍보 문구 — 「고문서 한 장」 템플릿

`studio.py promo`가 이 틀을 `mediate/<테마>/promo.md`에 만들어 둡니다. [대괄호] 칸만 채우고, **블록 사이에는 빈 줄 하나**를 그대로 둡니다 (인스타그램·유튜브에서 단락이 붙지 않게).

```
📜 고문서 한 장 EP.[두 자리 번호] 〈[제목 — 인물·장소가 드러나게]〉

[이모지 1개] [궁금증을 여는 질문 한 문장]

[소장처]에는 [무엇이 남아 있는지]. [문서를 시간 순서로 2~4문장 — 연도와 사실만]

이번 릴스에서는 [무엇을 따라가 봅니다]. 이 기록을 바탕으로 Claude 플러그인 aks-archive-harvester로 전시 웹페이지, 카드뉴스, 수업 활동지, SNS 게시글을 만들었습니다.
※ 설명은 문서명과 이미지를 바탕으로 만든 초안입니다. 정확한 판독은 원문 확인이 필요합니다.

여러분이라면 [문서 A]와 [문서 B] 중 어느 쪽을 먼저 펼쳐보고 싶으세요? 댓글로 남겨주세요.

#고문서한장 #[인물] #[장소] #[문서유형] #고문서 #한국고문서자료관 #디지털인문학 #Claude #오픈소스
```

## 칸 채우는 규칙

| 칸 | 규칙 |
|---|---|
| 제목 〈 〉 | 누가·어디·무엇이 한눈에. 예: 〈명성황후가 남긴 한글 편지〉, 〈임금의 부름에 나아가지 않은 선비, 윤증〉 |
| 첫 질문 | 이모지 1개 + 답이 궁금해지는 질문. 예: ✉️ 왕비가 세로로 흘려 쓴 한글, 본 적 있나요? |
| 본문 | `selection.csv`의 이야기·해제·요약에서 확인된 사실만. 연도 순서. 한 단락 (필요하면 줄바꿈 한 번) |
| 따라가 봅니다 | 영상이 보여 주는 것 한 구절. 그 뒤 플러그인 소개 문장은 그대로 |
| 댓글 질문 | 본문에 나온 문서 두 개를 고르게. "어느 쪽을 먼저 펼쳐보고 싶으세요?" |
| 해시태그 | 맨 앞 `#고문서한장`, 인물·장소·문서유형 3~6개, 맨 뒤 `#Claude #오픈소스` |

## 하지 않는 것

- 문서에서 확인되지 않은 일화·숫자("수십 번")를 넣지 않습니다. 셀 수 있으면 실제 수(고신 36점 등)를 씁니다.
- 판독이 불확실한 내용은 단정하지 않습니다 ("~로 보입니다", "원문 확인이 필요합니다").
- 이미지 출처 줄과 초안 안내(※) 줄은 빼지 않습니다.
