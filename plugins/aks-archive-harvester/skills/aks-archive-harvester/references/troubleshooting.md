# 문제 해결

| 증상 | 원인 | 대처 |
|---|---|---|
| 응답 본문이 `WEBFIREWALL BLOCK!!!` | 비브라우저 요청 또는 `X-Requested-With` 헤더 | 기본 헤더만 사용. 스크립트는 30초 대기 후 재시도 |
| manifest가 문서 0건 | 잘못된 `data-url`(문서 노드나 다른 itemId) 또는 일시 차단 | 폴더 노드(`L…`)의 data-url인지 확인, `&amp;`는 `&`로 |
| exit code 137 | 긴 두루마리 여러 장을 동시에 메모리에서 처리 | 다시 실행(이어받기). 반복되면 `--page-workers 1` |
| 명령이 10분 제한에 걸림 | 툴 실행 시간 상한 | `--time 540`으로 끊어 반복 실행 |
| `missing.txt`의 `XML404` | 서버에 그 페이지가 없음 | 수집 실패 아님. 목록에 표시하고 사용자에게 안내 |
| `partial.txt`의 `level a/b` | 최고 레벨 타일 일부가 서버에 없음 | 아래 레벨로 저장됨. 해상도를 함께 안내 |
| SendUserFile이 "exceeds the 400 MiB upload limit" | 첨부 용량 상한 | `pack --max-mb 350`으로 다시 분할 |
| 디스크 부족 | JPG 장당 약 3MB, ZIP 사본이 한 벌 더 생김 | 분류별로 ZIP 전달 후 `WORK/out/<분류>` 삭제 |
| 동시 요청을 올리는 명령이 거부됨 | 과도한 요청으로 판단 | 우회하지 말고 기본값으로 진행, 사용자에게 예상 시간 안내 |

## 규모 참고 (동춘당 송준길 후손가, 2026-11)

- 문서 497건 / 5,274장, 원본 약 11GB, 타일 요청 약 100만 건
- 기본 설정으로 약 2~4초/장, 전체 5~6시간
- 서버에 없는 장 38장, 저해상도 대체 13장
