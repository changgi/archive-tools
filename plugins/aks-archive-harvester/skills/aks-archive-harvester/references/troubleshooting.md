# 문제 해결

| 증상 | 원인 | 대처 |
|---|---|---|
| 응답 본문이 `WEBFIREWALL BLOCK!!!` | 비브라우저 요청 또는 `X-Requested-With` 헤더 | 기본 헤더만 사용. 스크립트는 30초 대기 후 재시도 |
| manifest가 문서 0건 | 잘못된 `data-url`(문서 노드나 다른 itemId) 또는 일시 차단 | 폴더 노드(`L…`)의 data-url인지 확인, `&amp;`는 `&`로 |
| exit code 137 | 긴 두루마리 여러 장을 동시에 메모리에서 처리 | 다시 실행(이어받기). 반복되면 `--page-workers 1` |
| 명령이 10분 제한에 걸림 | 툴 실행 시간 상한 | `--time 540`으로 끊어 반복 실행 |
| `missing.txt`의 `XML404` | 서버에 그 페이지가 없음 | 수집 실패 아님. 목록에 표시하고 사용자에게 안내 |
| `partial.txt`의 `level a/b` | 최고 레벨 타일 일부가 서버에 없음 | 아래 레벨로 저장됨. 해상도를 함께 안내 |
| SendUserFile이 "exceeds the 400 MiB upload limit" | 첨부 용량 상한 | `pack --max-mb 350`으로 다시 분할 |
| 디스크 부족 | JPG 장당 약 3MB, ZIP 사본이 한 벌 더 생김 | 분류별로 ZIP 전달 후 `WORK/out/<분류>` 삭제 |
| `find`가 아무것도 못 찾음 | 검색어가 사이트 표기와 다름 | 지역명·성씨·인물명 하나만 넣어 보기, `catalog`로 전체 목록 확인, `--refresh` |
| 카드뉴스 글자가 네모로 나옴 · 「⚠ 한글 글꼴을 찾지 못해」 | 한글 글꼴을 못 찾음(도구가 정해 둔 자리와 글꼴 폴더를 찾아보고, '한'이 실제로 그려지는지까지 확인) | `selftest.py`의 「환경」에서 어느 글꼴을 쓰는지 확인 → 없으면 설치(Ubuntu/Debian `sudo apt install fonts-noto-cjk` · Fedora `sudo dnf install google-noto-sans-cjk-fonts`) 또는 `mediate --font 글꼴.ttf` |
| SSL 인증서 오류 | 회사·학교 프록시, 오래된 certifi | 스크립트는 시스템 인증서 저장소도 사용. `REQUESTS_CA_BUNDLE`로 기관 인증서 지정 |
| 무엇이 문제인지 모르겠음 | 설치 · 글꼴 · 인코딩 등 | `python3 scripts/selftest.py`(인터넷 불필요, 가짜 서버로 수집까지) → 실패한 줄의 메시지 |
| Windows에서 `UnicodeEncodeError` · 깨진 글자 | 출력이 cp949 파일 · 파이프로 감 | 최신 스크립트는 그대로 계속함. 화면에서는 정상. 1.0.2 이전 `docs.json`도 읽음 |
| 영상: `ffmpeg이 필요합니다` | ffmpeg 없음 | `winget install ffmpeg` · `brew install ffmpeg` |
| 영상: `내레이션 생성 실패` · `CERTIFICATE_VERIFY_FAILED` | 기관망 자체 인증서 | `AKS_CA_BUNDLE=<인증서 파일>` 또는 `--no-tts` |
| 카드의 옛한글(ᄒᆞ 등)이 풀어져 보임 | Pillow에 글자 조합(libraqm) 없음 | 웹페이지는 정상(글꼴 조각). 카드는 libraqm이 있는 환경에서 다시 만들기 |
| `check`에 「인용 원문 불일치」 | 이야기의 "현대어(原文)"에서 原文 중간 글자(불확실 글자 · 겹친 말)를 말없이 건너뛰었거나, 판독에 없는 글자를 인용 | 건너뛴 자리에 「…」를 넣거나("累日飢餓 … 將絶命"), 판독과 글자 그대로 맞춤. (?) · 띄어쓰기 · 문장부호 차이는 괜찮음 |
| `check`에 「날짜 어긋남」 | 연호 · 왕대 N년, 간지, 서기 가운데 하나가 다름(옮겨 적을 때 한 해 밀림, 간지 오타, 연호 혼동) | 원본 사진에서 날짜 줄을 다시 읽고 `studio.py fix`로 고침. 원문 자체가 어긋나면 원문은 그대로 두고 해제에 "한 해 어긋남 — 원문 확인 필요"를 적음 |
| 카드 · 영상 첫 장면이 검거나 비어 보임 | 대표 면이 표지 · 겉면 | `studio.py check`로 확인 → `studio.py page --n N --page 002.jpg` |
| 첫 페이지에 홍보 글 · 영상 칸이 없음 | promo · 영상을 mediate 뒤에 만듦 | `mediate` 다시(같은 명령을 다시 돌려도 중복되지 않음) |
| 카카오톡 · SNS 링크에 그림이 안 나옴 | 공개 주소를 안 줌(미리 보기 그림은 절대 주소여야 함) | `mediate --url` · `series.py --site-url`로 다시. 카카오 공유 디버거에서 캐시 지우기 |
| `fix`가 문서를 못 찾음 | 다른 테마이거나 자료 ID가 비어 있음 | `--theme` 확인, `--n 순서`로 지정 |
| `fix` 미리 보기에 "칸 전체가 바뀝니다" | 제보 내용이 구절인데 칸 전체로 읽음 | `--replace-part "이전 구절"` (제보가 "이전 → 이후" 꼴이면 자동) |
| 시리즈 사이트 용량이 큼 | 웹용 영상이 없어 원본 크기 영상이 복사됨 | `video.py … --web` 후 `series.py` 다시 |
| 동시 요청을 올리는 명령이 거부됨 | 과도한 요청으로 판단 | 우회하지 말고 기본값으로 진행, 사용자에게 예상 시간 안내 |

## 규모 참고 (동춘당 송준길 후손가, 2026-11)

- 문서 497건 / 5,274장, 원본 약 11GB, 타일 요청 약 100만 건
- 기본 설정으로 약 2~4초/장, 전체 5~6시간
- 서버에 없는 장 38장, 저해상도 대체 13장
