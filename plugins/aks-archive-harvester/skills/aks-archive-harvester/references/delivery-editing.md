# 전달 에디팅 — 고른 기록을 어떻게 전할 것인가

큐레이션은 "무엇을 고를까", **문구 에디팅**은 "무엇을 말할까"(selection.csv의 캡션·이야기를 원문에 맞게 고쳐 쓰기), **전달 에디팅**은 "어떻게 · 무엇으로 · 어디로 전할까"입니다. 같은 기록, 같은 사실도 표현과 물질, 통로와 매개에 따라 지나가는 정보가 되기도 하고 마음에 남는 기억이 되기도 합니다. 같은 악보도 연주와 공연장에 따라 다르게 들리는 것과 같습니다.

## delivery.md 항목

| 항목 | 쓸 것 |
|---|---|
| 핵심 정서 | 보는 사람 마음에 남길 한 가지 감정 (예: 그리움, 경외, 억울함에서 안도로) |
| 한 문장 | 이 묶음이 끝내 전하려는 말 |
| 열기 | 첫 장면 — 질문이나 낯선 한 줄로 시작 |
| 펼치기 | 문서를 어떤 순서·대비로 보여 줄지 |
| 절정 | 가장 힘을 줄 원문 한 줄과 그 순간의 연출 |
| 여운 | 마지막 장면 — 무엇을 남기고 끝낼지 |
| 감각과 물질 | 종이·빛·소리·냄새·크기·손으로 만지는 복제 등 물질과 감각의 장치 |
| 통로와 매개 | 온라인·오프라인 어떤 통로로, 어떤 순서로 만나게 할지 |
| 여운 장치 | 보는 사람이 참여하고 기억하게 하는 장치 (질문, 쓰기, 남기기) |
| 전달 에디팅 전 | 기록을 그대로 늘어놓았을 때의 모습 |
| 전달 에디팅 후 | 같은 기록을 설계해 전했을 때의 모습 |

## 장면 설계 — 네 박자

1. **열기**: 질문이나 낯선 한 줄(첫 2초, 첫 벽).
2. **펼치기**: 순서와 대비(공/사, 높이/낮음, 영광/빚, 이두/국한문).
3. **절정**: 원문 한 줄에서 멈추기 — 그 한 줄만 크게, 소리를 줄이거나 끊기.
4. **여운**: 「남겨 둔 질문」으로 끝내고 답은 보는 사람에게.

## 문서 유형별 물질 · 감각 제안 (`delivery_draft`가 쓰는 표)

| 문서 유형 | 제안 |
|---|---|
| 홍패 | 붉은 종이를 실물 크기로 복제해 벽에 거는 연출 |
| 백패 | 흰 종이 한 장에 조명 하나 |
| 고신 · 교지 · 칙명 · 관고 · 차첩 | 어보·관인 탁본 스탬프를 찍어 보는 체험 |
| 유지 · 유서 | 역마 방울·말발굽 소리와 함께 펼치는 두루마리 |
| 교서 · 녹권 | 두루마리를 실제 길이로 펼친 복제 |
| 편지 · 간찰 · 언간 · 엽서 · 어찰 | 손바닥 크기 복제를 직접 들고 읽기, 낭독 음성 |
| 소지 · 상서 · 등장 · 의송 · 청원 | 연명한 이름을 벽에 길게 나열하고 관아 마당처럼 서서 읽는 동선 |
| 분재기 · 명문 · 매매 · 차용 · 계약 | 값(무명·냥·원)을 오늘의 물건으로 바꿔 옆에 놓기, 수결 따라 그리기 |
| 절목 · 완문 · 규약 · 약속 · 향약 · 동계 | 규약을 판에 새기고 관람객이 자기 규칙을 써 보는 벽 |
| 호적 · 호구 · 지패 · 준호구 | 나의 신분증 만들기 체험 카드 |
| 홀기 | 집례 목소리로 읽고 동작을 따라 하기 |
| 시권 | 시험장 책상과 답안지 체험 |
| 제문 · 만사 · 치제 | 조명을 낮추고 낭독, 촛불 |
| 초상 · 영정 | 여러 번 다시 그린 얼굴을 투명 레이어로 겹치기 |
| 사전 · 물명고 · 책 · 첩 | 책장을 넘기는 소리, 확대 열람대 |

## 통로와 매개 — 순서

온라인: 릴스(열기) → 카드뉴스(펼치기) → 전시 웹페이지(절정·원문) → 비하인드 카드(여운) / 오프라인: 원본 크기 복제 · 낭독 · 참여 벽 / 남기기: 활동지 · 질문 카드.

## 지킬 것

- 민감한 기록(기근 · 노비 · 자매 · 형벌)은 감정을 자극하는 연출보다 존엄을 먼저 — 조명·소리를 줄이고, 이름을 불러 주는 방식.
- 물질 연출(복제 · 탁본 체험)은 원본이 아닌 복제로, 이미지 사용은 소장처 동의.
- 설계는 문서에 있는 사실 위에서 — 각색이 들어가면 밝히기.
