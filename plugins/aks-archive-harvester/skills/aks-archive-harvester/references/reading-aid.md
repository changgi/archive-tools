# 읽기 도움 — 판독 · 해제 · 내용 요약 쓰는 법

고문서는 옛 한자, 이두(한자로 적은 우리말 토씨), 흘림 글씨(초서), 옛 한글 편지(언간)로 되어 있어 지금 사람이 바로 읽기 어렵습니다. `selection.csv`의 세 칸을 채우면 `mediate`가 전시 웹페이지의 「읽기 도움」 상자와 활동지의 「어떤 문서? · 무슨 내용? · 원문 속 글자」로 넣습니다.

| 칸 | 쓰는 것 | 규칙 |
|---|---|---|
| `판독` | 이미지에서 실제로 읽은 핵심 글자 (첫머리, 이름, 관직, 날짜, 도장·겉봉 글씨) | 줄 바뀜은 ` / `. 못 읽은 글자는 □. 확신이 없으면 끝에 "(판독 불확실)". 읽을 수 없으면 괄호로만 "(흘림 글씨 — 판독 필요)" — 이때 활동지의 「원문 속 글자」는 자동으로 빠집니다 |
| `해제` | 언제(연호 → 서기, 임금 재위년) · 누가 · 누구에게 · 어떤 서식의 문서인지 · 읽는 법 | `edit`가 유형별 서식 설명으로 초안을 넣어 둡니다. 이미지에서 확인한 사실로 고칩니다 |
| `요약` | 현대어로 풀어 쓴 내용 2~4문장 | 서식이 정해진 문서는 끝까지 풀어 쓰고, 긴 글은 읽은 만큼만 요약하고 "본문 판독 필요"라고 밝힙니다 |

모두 초안입니다. 사람이 원문을 확인한 줄에만 `검토`=`확인`을 넣습니다.

## 작업 순서

1. `contact_sheet.jpg`로 전체를 보고, 문서마다 `images/NN.jpg`를 Read로 엽니다. 글씨가 작으면 PIL로 잘라 확대해서 다시 봅니다.
2. 큰 글씨(첫머리·이름·날짜)부터 읽습니다. 연호와 간지는 서기로 바꿉니다 (예: 乾隆十四年 = 1749, 영조 25).
3. 문서명과 이미지가 어긋나면 숨기지 말고 해제에 적습니다 (예: 문서명은 "모후에게"인데 겉봉에 "明安公主房").
4. 첩(帖)·묶음 이미지는 그 면이 문서명의 문서인지 확인할 수 없으므로 "첩 이미지라 면 대조는 원문 확인 필요"를 붙입니다.

## 서식별 읽는 법 (자주 나오는 것)

| 유형 | 서식 | 판독 예 → 요약 |
|---|---|---|
| 고신·교지 | `敎旨` → `이름 爲 품계 + 行/守 관직 者` → `연호 年 月 日` + 임금 도장 | 敎旨 / 安鼎福爲通訓大夫行濟用監主簿者 / 乾隆三十年七月二十四日 → 안정복을 통훈대부 행 제용감 주부로 삼는다 |
| 이조·병조 명의 고신 | `吏曹 (날짜) 奉 / 敎 이름 爲 … 者` (낮은 관직) | 吏曹乾隆十四年五月十二日奉 敎 … 爲通德郞行厚陵參奉者 |
| 홍패·백패 | `敎旨` → `이름 武科/文科 丙科 第五人 及第出身者` | 한량 유이주가 무과 병과 제5인으로 급제 |
| 추증교지 | `贈`이 붙은 관직·작호, 왼쪽 작은 글씨에 근거 (`依法典從夫職`, `依大典追贈`) | 숙부인 성씨를 정부인으로 높인다 — 남편의 품계를 따름 |
| 증시교지 | `贈諡 ○○公者` | 정온에게 문간공 시호 |
| 유지 | `今以爾爲 관직 爾其斯速乘馹上來事 有旨` → 날짜 → 승지 직함·성 | 지평으로 삼으니 역마를 타고 속히 올라오라 |
| 녹패 | `吏曹奉 敎賜 품계 이름 今○○年 第○科祿者` | 경술년 제○과 녹봉을 내린다 |
| 명문 | `年月日 ○○前明文` → `右明文爲 …` 사유·대상·값 → 주인·증인·필집 서명 | `○○前明文`의 ○○은 **산 사람**(문서를 받는 사람) |
| 준호구·호구단자 | 주소 → 호주(직역·이름·나이·본관) → 4조 → 아내와 4조 → 자녀 → 노비 | |
| 고목 | `告目` → 보고 내용 → `爲白乎事` → 날짜 · 직책 · 이름 | 녹미 324섬, 콩 197섬을 내어 주었음을 보고 |
| 등장·소지 | 사연 → 청원자 명단 → 왼쪽 아래 관의 처분(題辭), 큰 붓 자국은 수령 서명 | |
| 절목·완문 | 서문 → `一 …事` 조항 → 날짜·관인 | 一 禁衛廳勿侵事 → 금위청은 침범하지 말 것 |
| 상량문 | 제목 → 내력 → `兒郞偉 拋樑東/西/南/北/上/下` 축원 → 날짜·지은 이 | |
| 언간(한글 편지) | 흘림, 세로, 오른쪽 줄부터. 안부 → 용건. 여백·행간에 이어 쓰기 | 글시 보고 밤ᄉᆞ이 잘 잇던 일 든든ᄒᆞ며 → 편지 보고 밤사이 잘 지낸 일 든든하며 |

## 이두·관용어

| 글자 | 읽기 | 뜻 |
|---|---|---|
| 乙良 | 을랑 | ~은/는 (주제) |
| 是白乎事 / 爲白乎事 | 이삷온 일 / 하삷온 일 | ~이옵는 일 / ~하옵는 일 (보고 끝맺음) |
| 敎是 | 이시 | ~하시는 (상대 높임) |
| 爲乎事 | 하온 일 | ~하는 일 |
| 段 | 단 | ~은/는 |
| 前明文 | 앞 명문 | ~에게 써 주는 계약서 |
| 承傳 | 승전 | 임금의 명을 받들어 전함 |
| 行 / 守 | 행 / 수 | 품계가 관직보다 높음 / 낮음 |
