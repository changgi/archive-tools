## 2. 유튜브 (16:9)
**제목**
```
서원을 지키고 꾸린 기록 — 함양 남계서원 | 고문서가 전시·카드뉴스가 되기까지 (EP.5)
```
**설명**
```
서원은 공부만 하던 곳이었을까요? 📜

함양 남계서원은 논밭을 장부(양안)에 적어 관리했고,
1843년 완문에는 금위청·어영청 등이 "침범하지 말 것(勿侵事)"이라는 조항이 줄지어 있습니다.
문루를 올릴 때는 상량문을 짓고, 건물 배치는 한 장의 그림(건치도)으로 남겼습니다.

한국고문서자료관의 고문서를 Claude 플러그인 aks-archive-harvester로 모으고(수집), 정리하고(큐레이션), 다듬어(에디팅), 전시·교육 자료로 잇는(매개) 과정을 보여 줍니다.

▶ 이 예시의 결과물(전시 웹페이지·카드뉴스·활동지): https://changgi.github.io/archive-tools/examples/namgye-seowon/exhibit.html
▶ 전체 예시 갤러리: https://changgi.github.io/archive-tools/examples/
▶ 설치·소스: https://github.com/changgi/archive-tools

설치 (Claude Code / Cowork)
/plugin marketplace add changgi/archive-tools
/plugin install aks-archive-harvester@changgi-archive-tools

※ 설명은 문서명과 이미지에 근거한 초안이며, 판독·해석은 원문 확인이 필요합니다.
※ 이미지: 한국학중앙연구원 한국고문서자료관 소장·제공 · 함양 남계서원 (재사용은 자료관 문의)

만든 사람: Song Chang-gi
```
